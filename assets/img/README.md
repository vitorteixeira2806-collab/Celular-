# Imagens da landing page

Coloque aqui as fotos da LP original (lp.artecgal.com.br). Enquanto o arquivo não existir,
a página exibe automaticamente um fundo metálico gerado em CSS/SVG no lugar da foto.

| Arquivo          | Onde aparece                         | Tamanho sugerido |
| ---------------- | ------------------------------------ | ---------------- |
| `hero.jpg`       | Card principal do topo (hero)        | 800 × 960 px     |
| `zincagem.jpg`   | Card grande "Zincagem eletrolítica"  | 1200 × 800 px    |
| `galeria-1.jpg`  | Galeria (foto vertical, à esquerda)  | 700 × 900 px     |
| `galeria-2.jpg`  | Galeria (foto pequena, topo direito) | 700 × 450 px     |
| `galeria-3.jpg`  | Galeria (foto pequena, base direita) | 700 × 450 px     |

Para trocar o logotipo, substitua o SVG dentro de `.brand__mark` no `index.html`
ou aponte um `<img src="assets/img/logo.png">` no mesmo lugar.
